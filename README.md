<h1 align="center">Flick 弹指</h1>

<p align="center">为客厅大屏打造的私人影院播放器 · A private cinema player for Android TV</p>

本仓库只用于 **版本发布** 与 **问题反馈**，不包含源代码。

This repository only hosts **releases** and **issue reports** for Flick. It does not contain source code.

## 下载 / Download

从 [Releases](https://github.com/f4cker/Flick/releases/latest) 下载与设备架构对应的 TV 安装包。Download the TV package for your device's architecture from [Releases](https://github.com/f4cker/Flick/releases/latest).

| 架构 / Architecture | 安装包 / Package | 说明 / Notes |
|---|---|---|
| armeabi-v7a | `app-armeabi-v7a-tv-ui-release.apk` | 多数电视与盒子 / Most TVs and boxes |
| arm64-v8a | `app-arm64-v8a-tv-ui-release.apk` | 较新的 64 位盒子 / Newer 64-bit boxes |

要求 Android 7.0 及以上。已安装的版本可在「设置 › 关于 › 检查更新」中直接升级。

Requires Android 7.0 or later. Installed builds can upgrade from **Settings › About › Check for updates**.

## 反馈 / Feedback

遇到 Bug 或有功能建议，请提交 [Issue](https://github.com/f4cker/Flick/issues/new/choose)。一个 Issue 只描述一个问题。

Found a bug or have a suggestion? Open an [issue](https://github.com/f4cker/Flick/issues/new/choose), one problem per issue.
